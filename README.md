# Lista de Compras em Python

Programa de terminal para cadastrar itens de compra com nome e quantidade.
Os dados ficam salvos em um arquivo JSON, então continuam lá quando você
fecha e abre o programa de novo.

## Tecnologias
- Python 3
- Programação Orientada a Objetos
- Manipulação de arquivos (JSON)
- Código dividido em módulos

## Estrutura
- `item.py`: classe `Item`
- `armazenamento.py`: carregar e salvar os itens
- `main.py`: menu e fluxo principal

## Como rodar
1. Clone o repositório
2. (Opcional) crie e ative um ambiente virtual
3. Rode `python main.py`
